## 3. Mengelola Akun Pengguna

**Fitur ini untuk menambah akun baru** untuk guru atau admin lain.

### Cara Menambah Akun Baru:

1. **Klik menu "Kelola Pengguna"** 👤
   - Menu ini khusus untuk administrator

2. **Klik "Tambah Pengguna Baru"**

3. **Isi Data Akun:**
   
   | Field | Penjelasan | Contoh |
   |-------|------------|---------|
   | **Nama Lengkap** | Nama lengkap pengguna | "Ibu Siti Aminah, S.Pd" |
   | **Email** | Email untuk login | siti.aminah@skhtamianglayang.sch.id |
   | **Password** | Password sementara | Password123! |
   | **Role/Peran** | Hak akses pengguna | Pilih: Admin atau Guru |
   | **Nomor HP** | Nomor telepon (opsional) | 081234567890 |

4. **Tentukan Role/Peran:**
   - **Admin**: Akses penuh ke semua fitur
   - **Guru**: Akses terbatas (kelola produk, galeri, berita)

5. **Klik "Simpan"**

6. **Informasikan ke pengguna:**
   - Email login
   - Password sementara
   - Minta ganti password setelah login pertama

### Cara Mengedit Akun:

1. Cari nama pengguna di daftar
2. Klik tombol **"Edit"**
3. Ubah data yang diperlukan
4. Klik **"Update"**

### Cara Menghapus Akun:

1. Klik tombol **"Hapus"** di samping nama pengguna
2. **Konfirmasi** penghapusan
3. Akun akan dihapus dari sistem

> ⚠️ **PENTING**: 
> - Jangan hapus akun admin utama!
> - Pastikan password aman (min 8 karakter, ada huruf besar, angka, simbol)
> - Catat password dan berikan ke pengguna yang bersangkutan

### Tips Keamanan Akun:

✅ **DO (Lakukan):**
- Buat password yang kuat
- Ganti password secara berkala
- Hapus akun yang tidak aktif
- Catat semua akun yang dibuat

❌ **DON'T (Jangan):**
- Gunakan password yang sama untuk semua akun
- Bagikan password lewat chat/WA (langsung bertemu)
- Biarkan akun lama yang tidak dipakai

## 4. Mengelola Hero Banner

**Hero Banner** adalah gambar besar di bagian atas halaman.

### Cara Mengubah Hero Banner:

1. **Klik menu "Hero Banner"** 🎨

2. **Pilih halaman** yang ingin diubah:
   - Home (Homepage - ada 4 slide carousel)
   - Berita
   - Gallery
   - PPDB
   - Profile
   - Unduhan

3. **Upload Gambar Baru:**
   - Klik area **"Klik untuk upload gambar"**
   - Pilih foto dari komputer
   - Tunggu sampai upload selesai
   - **ATAU** masukkan URL gambar manual

4. **Isi Form:**
   - **Judul**: Judul yang ditampilkan di banner
   - **Subtitle**: Kalimat penjelas di bawah judul
   - **Urutan**: (Khusus homepage) urutan slide (1, 2, 3, 4)
   - **Status**: Centang jika ingin aktif ditampilkan

5. **Klik "Tambah"** (untuk banner baru) atau **"Update"** (untuk edit)

### Tips Upload Gambar:

✅ **Format yang didukung**: JPEG, PNG, WebP  
✅ **Ukuran maksimal**: 5 MB  
✅ **Resolusi yang bagus**: 1920 x 1080 pixel  
❌ **Jangan upload**: File video, GIF terlalu besar

## 4. Mengelola Berita

### Cara Menambah Berita Baru:

1. **Klik menu "Kelola Berita"** 📰

2. **Klik tombol "Tambah Berita Baru"**

3. **Isi Form Berita:**
   - **Judul**: Judul berita (contoh: "Upacara HUT RI Ke-79")
   - **Konten**: Isi berita lengkap
   - **Gambar**: Upload foto berita
   - **Kategori**: Pilih kategori (Kegiatan/Prestasi/Pengumuman)
   - **Tag**: Tambahkan kata kunci (contoh: upacara, kemerdekaan)

4. **Klik "Simpan"**

### Cara Mengedit/Hapus Berita:

- **Edit**: Klik tombol **"Edit"** pada berita → Ubah → Klik "Update"
- **Hapus**: Klik tombol **"Hapus"** → Konfirmasi

## 5. Mengelola Produk

**Produk** adalah hasil karya siswa yang dijual.

### Cara Menambah Produk:

1. **Klik menu "Kelola Produk"** 🛍️

2. **Klik "Tambah Produk Baru"**

3. **Isi Data Produk:**

## ❓ Troubleshooting

### Masalah Umum:

**1. Tidak bisa login**
- Cek koneksi internet
- Pastikan email & password benar
- Hapus cache browser (Ctrl+Shift+Del)

**2. Upload gambar gagal**
- Cek ukuran file (max 5 MB)
- Cek format file (harus JPEG/PNG/WebP)
- Coba refresh browser

**3. Perubahan tidak muncul di website**
- Tunggu 1-2 menit
- Refresh halaman (Ctrl+F5)
- Bersihkan cache browser

**4. Lupa password**
- Hubungi administrator teknis
- Jangan coba reset sendiri

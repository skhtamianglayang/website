=============================================
API ROUTES - STRUKTUR & INPUT/OUTPUT
=============================================

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 1. LOGIN API (USERNAME-BASED)                                                           │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│ Endpoint: POST /api/login                                                               │
│                                                                                         │
│ Deskripsi: Autentikasi user menggunakan USERNAME (bukan email)                          │
│ Input (JSON Body): { "username": "admin", "password": "admin123" }                      │
│ Output Success:                                                                         │
│   { "id": "...", "email": "...", "name": "...", "role": "admin" }                       │
│ Note: "name" field digunakan sebagai username untuk login                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 2. TEACHERS API                                                                         │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│ GET /api/teachers                                                                       │
│   Deskripsi: Mendapatkan semua data guru                                                │
│                                                                                         │
│ POST /api/teachers                                                                      │
│   Deskripsi: Menambah guru baru                                                         │
│   Input: { "name" (username), "email", "password", "phone" }                            │
│   Note: role otomatis di-set ke "teacher"                                               │
│                                                                                         │
│ PATCH /api/teachers/[id]                                                                │
│   Deskripsi: Update data guru                                                           │
│                                                                                         │
│ DELETE /api/teachers/[id]                                                               │
│   Deskripsi: Hapus guru (cascade delete products)                                       │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 3. PRODUCTS API                                                                         │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│ GET /api/products                                                                       │
│   Deskripsi: Mendapatkan semua produk beserta info guru                                 │
│                                                                                         │
│ POST /api/products                                                                      │
│   Deskripsi: Menambah produk baru                                                       │
│   Input: { "name", "price", "description", "image", "category", "teacherId", ... }      │
│                                                                                         │
│ PATCH /api/products/[id]                                                                │
│   Deskripsi: Update produk                                                              │
│                                                                                         │
│ DELETE /api/products/[id]                                                               │
│   Deskripsi: Hapus produk                                                               │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 4. NEWS API                                                                             │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│ GET /api/news                                                                           │
│   Deskripsi: Mendapatkan semua berita (sorted by date desc)                             │
│                                                                                         │
│ POST /api/news                                                                          │
│   Deskripsi: Menambah berita baru                                                       │
│   Input: { "title", "date", "excerpt", "image", "slug" }                                │
│                                                                                         │
│ PATCH /api/news/[id]                                                                    │
│   Deskripsi: Update berita                                                              │
│                                                                                         │
│ DELETE /api/news/[id]                                                                   │
│   Deskripsi: Hapus berita                                                               │
│                                                                                         │
│ SUB-ROUTES:                                                                             │
│ POST /api/news/[id]/images    - Upload gallery images for news                          │
│ POST /api/news/[id]/comments  - Add comment to a news article                           │

=============================================
FITUR UTAMA / MAIN FEATURES
=============================================

1. HOMEPAGE (/)
   - Hero Carousel, Stats, Sambutan, Featured Teachers/News, Shop Preview.

2. ADMIN DASHBOARD (/admin)
   - CRUD Berita (plus Gallery & Comments management)
   - CRUD Galeri, Profil Guru, Kepala Sekolah
   - CRUD Produk
   - CRUD PPDB Info
   - CRUD Unduhan (Downloads)
   - CRUD Akun Guru (Teachers) - add via username
   - Site Stats Management

3. TEACHER DASHBOARD (/teacher)
   - Login khusus guru (menggunakan username)
   - Management produk sendiri

4. SHOP (/shop)
   - Katalog produk karya siswa/guru
   - Support WhatsApp & Shopee links

5. BERITA (/berita)
   - Listing berita sekolah
   - Detail page includes: Article, Photo Gallery, Public Comments section.

6. GALERI (/gallery)
   - Foto kegiatan & fasilitas sekolah

7. PROFIL (/profile)
   - Visi Misi, Sejarah
   - Daftar Guru & Staff

8. PPDB (/ppdb)
   - Informasi lengkap pendaftaran siswa baru
   - Jadwal, Syarat, Lokasi, Kontak

9. UNDUHAN (/unduhan)
   - Daftar file publik yang bisa diunduh (SK, Formulir, dll)
   - Link ke Google Drive / Direct Link

=============================================
COMMANDS
=============================================

# Install dependencies
npm install

# Run development server
npm run dev

# Database commands
npx prisma migrate deploy     # Apply migrations
npx prisma generate           # Generate Prisma client
npx prisma db seed            # Seed database with demo data
npx prisma db push            # Push schema changes (dev)
npx prisma studio             # Open Prisma Studio (GUI)

# Build for production
npm run build
npm start
